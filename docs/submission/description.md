# CYBERANTE: Procedural Vector Poker-Combat Matrix

CYBERANTE turns poker hands into simultaneous tactical combat. Split five cards
into a three-card Assault and two-card Aegis, spend Flux to reshape ranks and
suits, and burn a card for a temporary power. Read your opponent and choose
Brace, Overcharge or Parry as you fight to win two rounds.

Play solo against three deterministic classical bot personalities, challenge a
friend through a room code or join link, or learn through four interactive
lessons. Neon vector graphics and reactive synthwave audio are generated in code
with Three.js, GLSL and Web Audio. The game downloads no image, model or audio
assets and runs in a browser.

Built with OpenAI Codex through a TypeScript specification-driven workflow,
with an authoritative multiplayer server and automated gameplay verification.

Play: https://holactie.com/cyberante/
